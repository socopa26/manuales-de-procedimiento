# Control documental

- **00_ORIGINALES/**: los nueve DOCX fuente. No deben modificarse ni sobrescribirse. Las nuevas versiones se trabajan fuera de esta carpeta.
- **01_INTEGRACION/**: versiones con las decisiones aprobadas incorporadas, pendientes de revisión independiente y aprobación de su integración. No son documentos oficiales.
- **02_APROBADOS_AUDITORIA_FINAL/**: procedimientos cuya integración haya superado la revisión independiente y recibido aprobación.
- **03_OFICIALES/**: documentos oficializados únicamente después de finalizar la auditoría transversal, resolver los pendientes institucionales y completar el proceso de oficialización. Sin documentos por ahora.

Los archivos `.gitkeep` permiten conservar en Git las carpetas sin documentos; no representan procedimientos ni aprobaciones.
